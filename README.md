
# Zerodha Clone

A responsive stockbroker landing page built using React and CSS as a frontend development project.

## Features

- Responsive navigation bar
- Hero section with signup button
- Investment feature cards
- About and pricing sections
- Footer with navigation links
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- Git and GitHub

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Ashu211006/Zerodha-Clone.git
   ```

2. Open the project folder:

   ```bash
   cd Zerodha-Clone
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.
